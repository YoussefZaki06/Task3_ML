# Task 3 - Machine Learning Task

This repository contains my Task 3 machine learning assignment covering fundamental regression, classification, clustering, dimensionality reduction, and machine learning pipelines.

## Topics Covered

- Linear Regression from scratch using the Normal Equation
- Polynomial Regression
- Logistic Regression
- Decision Tree Classification
- Random Forest Classification
- K-Nearest Neighbors (KNN)
- K-Means Clustering
- PCA Dimensionality Reduction
- Scikit-learn Pipelines

## Dataset

The assignment uses the datasets specified in the task, including the Breast Cancer Wisconsin dataset and synthetic clustering data.
